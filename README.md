# Практическая работа 4

Для миграций и проверки бэкапа нужен Docker. Скрипт создаёт отдельные
контейнеры и сеть, последовательно применяет миграции, проверяет схему
и пробует восстановить дамп во временную базу.

```bash
bash scripts/ci.sh
```

GitHub Actions запускает тот же скрипт на раннере с метками
`self-hosted`, `Linux`, `X64`, `vbox` при push в main, вручную и по
расписанию в 23:00 UTC (02:00 по Москве).

Для диагностики, каталогового дампа и PITR нужны серверные и клиентские
утилиты PostgreSQL 17 в PATH и модуль pg_stat_statements. Запускайте от
обычного пользователя с новым каталогом и свободными локальными портами.

```bash
PATH=/usr/lib/postgresql/17/bin:$PATH bash scripts/run_lab.sh ./lab-output
```

Проверка отдельной БД использует стандартные параметры подключения libpq
и требует права создавать временные базы.

```bash
bash scripts/verify_backup.sh backup_lab public.users
```
